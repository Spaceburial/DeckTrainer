# DeckTrainer 使用说明（Steam Deck / SteamOS 通用游戏修改器）

一个程序，所有游戏通用：Steam/Proton 游戏、非 Steam 游戏、原生 Linux 游戏、模拟器都能用（附加任何正在运行的进程即可）。
**不需要下载第三方修改器、不需要安装 Python**——`DeckTrainer` 是自带运行时的独立可执行文件，解压即用。

当前版本：v2.1（独立可执行 + 自动附加 + 全类型搜索 + 收藏自动重定位 + 诊断工具）

---

## 一、它是什么、不是什么

- 原生 Linux 内存修改工具：直接读写游戏进程内存，搜索血量、金钱、弹药等数值的真实地址，改值或秒级锁定。
- 非暂停式读写，不会把游戏冻住，边玩边搜。
- **不是一键无敌外挂**：任何游戏第一次都要现场搜 2~3 轮定位（这是"零下载、全游戏通用"的代价）。
- 搜过一次并收藏后，下次开游戏自动复原地址，接近一键。
- 仅限单机游戏自娱自乐，不要用于联机对战。

## 二、安装（一次，1 分钟）

1. 把整个 `DeckTrainer` 文件夹放到 `/home/deck/DeckTrainer/`（放别处也行，后面路径替换）。
   文件夹里应包含：`DeckTrainer`（可执行文件）、`start.sh`、`DeckTrainer.desktop`、`诊断.sh`。
2. 在 Konsole 里执行一次，给它执行权限：

   ```bash
   chmod +x ~/DeckTrainer/DeckTrainer ~/DeckTrainer/start.sh ~/DeckTrainer/诊断.sh
   ```

3. 右键 `DeckTrainer.desktop` → 属性 → 勾选"允许作为程序执行"。

> 不需要 Python，不需要 sudo，不需要联网。

## 三、两种用法

### 方式 A：游戏模式 + 手机遥控（强烈推荐，免密码）

Steam 库 → 右键游戏 → 属性 → 通用 → 启动选项，填：

```
bash "/home/deck/DeckTrainer/start.sh" %command%
```

之后每次正常启动游戏：修改器随游戏自动启动，并**自动附加游戏进程**（界面上不用再手动选进程）。
手机与 Deck 连同一 Wi-Fi，浏览器打开 `http://Deck的IP:8766`。

查 Deck 的 IP：桌面模式 Konsole 执行 `hostname -I`，或看 `~/DeckTrainer/last_url.txt` 里自动记录的地址。

### 方式 B：桌面模式（附加已运行的游戏）

双击 `DeckTrainer.desktop`（或 `bash ~/DeckTrainer/start.sh`），浏览器打开 `http://127.0.0.1:8766`，在界面里选进程附加。

注意：SteamOS 默认的 deck 用户**没有密码**，桌面模式下直接 `sudo` 会失败。需要先在 Konsole 执行一次：

```bash
passwd
```

设置一个密码后再运行本方式。不想设密码就用方式 A。

> 日常推荐方式 A；两种方式不要同时用。

## 四、搜索流程（通用套路）

### 改钱 / 弹药 / 点数（有数字显示）

1. 输入游戏里看到的数字（如 1250），点"全类型搜索"——一次同时尝试 4/8 字节整数、单/双精度小数，不用猜类型。
2. 回游戏花掉/获得一些，数值变成 800 → 输入 800 点"精确值"。重复到剩 1~3 个候选。
3. 逐行试着改，确认是目标后点"锁定"（每 50ms 自动回写）。

### 改血量（血条没有数字）

1. 类型选"单精度小数"（多数游戏血量是 float）。
2. 点 **模糊快照(实验)** → 回游戏被打一下 → 点"减少" → 再被打 → 再"减少"。
3. 剩几条候选时逐行试锁定，血条不再掉就是对了。

### 收藏自动重定位（重点）

1. 定位成功后，在结果行点 **★**，起个名字（如"残尘"/"生命"）。
2. 收藏时自动记录"模块文件 + 偏移"（模块内地址）或"绝对地址 + 当时值"（堆地址）。
3. 下次开游戏，附加后"⑤ 收藏自动恢复"会显示 **已恢复 / 值已变 / 失效**：已恢复的直接点"锁定"；失效的点"重搜"。

## 六、出问题了怎么办

1. 桌面模式打开 Konsole，运行：

   ```bash
   bash ~/DeckTrainer/诊断.sh
   ```

   它会把系统版本、可执行文件、进程列表、端口、最近日志、Steam 启动选项全部写进
   `~/DeckTrainer/诊断报告.txt`，把这个文件发出来即可定位。

2. 常见现象对照：

| 现象 | 原因/处理 |
| --- | --- |
| 加了启动选项后游戏起不来或黑屏 | 启动选项路径写错：确认 `~/DeckTrainer/start.sh` 存在且 `chmod +x`；先在 Konsole 手动执行 `bash ~/DeckTrainer/start.sh %command%` 形式验证 |
| 手机打不开 8766 页面 | 确认同一 Wi-Fi、IP 正确；看 `~/.DeckTrainer/last_url.txt`；公共 Wi-Fi 的 AP 隔离不行 |
| 界面里没有游戏进程 | 游戏还没进主界面；或点"刷新"；看诊断报告里的进程列表 |
| 附加失败/权限不足 | 用方式 A（父进程，免密码）；方式 B 需先 `passwd` 设密码 |
| 桌面模式 sudo 报密码错误 | SteamOS 默认无密码，先 `passwd` 设置 |
| 搜到 0 个结果 | 换"全类型搜索"；数值可能是显示取整（用模糊模式）；少数游戏数值加密 |
| 候选几十万个 | 数值太常见（0、1、100），换更独特的数值 |
| 写入后没变化 | 多个候选逐个试；同一数值可能有两份，要都锁 |
| 锁定后闪退 | 锁错地址，立即"解除"并重启游戏（本工具不改存档） |
| 收藏恢复失败 | 堆地址每次启动会变，属正常，用"重搜"重新定位后再收藏 |

- 端口占用：启动前设 `DECKTRAINER_PORT=9000`。
- 运行日志：`~/DeckTrainer/运行日志.txt`（每次启动都会追加）。

## 七、安全须知

- 仅单机离线使用；联机游戏改内存可能触发反作弊，本工具不为此负责。
- 网页界面默认对整个局域网开放（方便手机遥控），不要在不可信网络下长期开启。
- 重要存档先备份（Steam 云同步 + 手动复制存档）。
