# DeckTrainer 使用说明（Steam Deck / SteamOS 通用游戏修改器）

一个程序，所有游戏通用：Steam/Proton 游戏、非 Steam 游戏、原生 Linux 游戏、模拟器都能用（附加任何正在运行的进程即可）。
**不需要下载任何第三方修改器、不需要安装依赖**，全部是本目录文件 + Deck 自带 Python。

当前版本：v2（全类型搜索 + 任意进程 + 收藏自动重定位）

---

## 一、它是什么、不是什么

- 原生 Linux 内存修改工具：直接读写游戏进程内存，搜索血量、金钱、弹药等数值的真实地址，改值或秒级锁定。
- 非暂停式读写，不会把游戏冻住，边玩边搜。
- **不是一键无敌外挂**：任何游戏第一次都要现场搜 2~3 轮定位（这是"零下载、全游戏通用"的代价）。
- 但 v2 起支持**收藏自动重定位**：搜过一次并收藏后，下次开游戏附加即自动复原地址，接近一键。
- 仅限单机游戏自娱自乐，不要用于联机对战。

## 二、安装（一次，2 分钟）

1. 把整个 `DeckTrainer` 文件夹复制到 Deck 根目录，路径为 `/home/deck/DeckTrainer/`（放别处也行，后面路径替换）。
2. 右键 `DeckTrainer.desktop` → 属性 → 勾选"允许作为程序执行"。
3. 完成。

## 三、两种用法

### 方式 A：游戏模式 + 手机遥控（推荐）

Steam 库 → 右键游戏 → 属性 → 通用 → 启动选项，填：

```
bash "/home/deck/DeckTrainer/start.sh" %command%
```

之后每次正常启动游戏，修改器自动跟着启动（它是游戏父进程，不需要 sudo）。手机与 Deck 连同一 Wi-Fi，浏览器打开 `http://Deck的IP:8766`。
首次可在桌面模式跑一次记下 IP（也可在 Konsole 用 `hostname -I` 查）。

### 方式 B：桌面模式本地窗口

双击 `DeckTrainer.desktop`（或 `bash /home/deck/DeckTrainer/start.sh`），输入 sudo 密码，浏览器打开 `http://127.0.0.1:8766`。
桌面模式下修改器不是游戏父进程，需要管理员权限读内存。

> 日常推荐方式 A；两种方式不要同时用。

## 四、搜索流程（通用套路）

### 改钱 / 弹药 / 点数（有数字显示）

1. **① 附加进程**：下拉框选中游戏（Steam/Proton/Wine/原生进程都在列表里，可按名称筛选），点"附加"。
2. **② 全类型搜索**：输入游戏里看到的数字（如 1250），点"全类型搜索"——它会一次同时尝试 4/8 字节整数、单/双精度小数，不用猜类型。
3. 回游戏花掉/获得一些，数值变成 800 → 输入 800 点"精确值"。重复到剩 1~3 个候选。
4. **③ 写入/锁定**：逐行试着改，确认是目标后点"锁定"（每 50ms 自动回写）。

### 改血量（血条没有数字）

1. 类型选"单精度小数"（多数游戏血量是 float）。
2. 点 **模糊快照(实验)** → 回游戏被打一下 → 点"减少" → 再被打 → 再"减少"。
3. 剩几条候选时逐行试锁定，血条不再掉就是对了。

### 收藏自动重定位（v2 新增，重点）

1. 定位成功后，在结果行点 **★**，给它起个名字（如"残尘"/"生命"）。
2. 收藏时自动判断地址类型：
   - **模块内地址**：记录"模块文件 + 偏移"，下次游戏启动后按新基址自动算出地址，最可靠；
   - **堆地址**：记录绝对地址 + 当时的值，下次按值校验，可能失效（堆地址每次启动会变）。
3. 下次开游戏，附加后打开"⑤ 收藏自动恢复"卡片：显示 **已恢复 / 值已变 / 失效**，已恢复的直接点"锁定"即生效；失效的用"重搜"重新搜当前值。

## 六、常见问题

- **进程列表是空的**：游戏还没启动；本工具只列内存占用 ≥8MB 的进程。
- **附加失败/权限不足**：游戏模式用"方式 A"启动选项（父进程免 sudo）；桌面模式用 `start.sh` 走 sudo。
- **搜到 0 个结果**：换"全类型搜索"；数值可能显示取整（试模糊模式）；少数游戏数值加密，搜不到。
- **候选几十万个**：数值太常见（0、1、100），换更独特的值，或模糊 + 多次"减少"。
- **写入后没变化**：多个候选逐个试；有的游戏同一数值有两份，要都锁。
- **锁定后闪退**：锁错地址，立即"解除"并重启游戏；本工具只改内存，不动存档。
- **收藏下次恢复失败**：堆地址本身会变，属正常，用"重搜"重新定位后再收藏一次。
- **端口占用**：启动前设 `DECKTRAINER_PORT=9000`。
- **手机连不上**：确认同 Wi-Fi、IP 正确；公共 Wi-Fi 的 AP 隔离环境不行。

## 七、安全须知

- 仅单机离线使用；联机游戏改内存可能触发反作弊，本工具不为此负责。
- 网页界面默认对整个局域网开放（方便手机遥控），不要在不可信网络下长期开启。
- 重要存档先备份（Steam 云同步 + 手动复制存档）。
