# DeckTrainer 使用说明（Steam Deck / SteamOS 通用游戏修改器）

一个程序，所有游戏通用：Steam/Proton 游戏、非 Steam 游戏、原生 Linux 游戏、模拟器都能用。
**不需要下载第三方修改器，不需要安装 Python**——`DeckTrainer` 是自带运行时的独立可执行文件，解压即用。

当前版本：**v2.2**（游戏启动保护 + 自动识别已启动游戏 + 自动识别游戏/引擎/属性 + 收藏自动恢复 + 诊断）

---

## 一、它是什么、不是什么

- 原生 Linux 内存修改工具：直接读写游戏进程内存，搜索血量、金钱、弹药等数值的真实地址，改值或秒级锁定。
- 非暂停式读写，不会把游戏冻住，边玩边搜。
- **会自动识别游戏**：游戏一启动就自动附加，显示游戏名、引擎（Unity/Unreal/REDengine…）、32/64 位、AppID，并给出该游戏的属性预设。
- **不是一键无敌外挂**：任何游戏第一次仍要现场搜 2~3 轮（内存里没有"血量"这种名字，只有数字）；搜过一次收藏后，下次自动复原地址。
- 仅限单机游戏自娱自乐，不要用于联机对战。

## 二、安装（一次，1 分钟）

1. 把整个 `DeckTrainer` 文件夹放到 `/home/deck/DeckTrainer/`。
2. Konsole 执行一次：

   ```bash
   chmod +x ~/DeckTrainer/DeckTrainer ~/DeckTrainer/*.sh
   ```

3. （可选）右键 `DeckTrainer.desktop` → 属性 → 勾选"允许作为程序执行"。

> 不需要 Python、不需要联网。装好后先跑一次 `~/DeckTrainer/DeckTrainer --version`，应输出 `DeckTrainer v2.2`。

## 三、三种启动方式（按顺序选一种）

### 方式 A：Steam 启动选项（最稳，免密码，推荐）

Steam 库 → 右键游戏 → 属性 → 通用 → 启动选项，填：

```
bash /home/deck/DeckTrainer/start.sh %command%
```

> 路径有空格才需要引号；普通路径不要加引号，避免 Steam 解析差异。

之后正常启动游戏即可。v2.2 起：

- **游戏一定会先启动**，修改器再初始化；修改器自身失败不会挡住游戏。
- 端口被占用会自动换端口（8766→8767…），不会因此退出。
- 启动脚本会先自检，可执行文件坏掉时直接放行游戏。

手机与 Deck 连同一 Wi-Fi，浏览器打开 `http://Deck的IP:8766`（换过端口就看 `~/DeckTrainer/last_url.txt`）。

### 方式 B：后台自动识别（完全不加启动选项）

适合"不想动 Steam 启动选项"或想随时换游戏：

1. 桌面模式双击 `后台模式.sh`（或 Konsole 执行 `bash ~/DeckTrainer/后台模式.sh`）。
2. 正常启动任意游戏，修改器自动发现并附加，自动识别游戏与属性。
3. 关掉修改器：Konsole 执行 `pkill -f 'DeckTrainer --hub'`。

如果界面提示"无法读取该进程内存/权限不足"，在 Konsole 运行一次：

```bash
bash ~/DeckTrainer/开放权限.sh
```

（会要求密码；SteamOS 默认 deck 用户没密码，先执行 `passwd` 设一个。设置后重启也有效。）

> 方式 B 的优点是随时可用、不绑定游戏；缺点是首次需要这一次权限设置。

### 方式 C：桌面模式

双击 `DeckTrainer.desktop`（或 `bash ~/DeckTrainer/start.sh`），浏览器打开 `http://127.0.0.1:8766`。
桌面模式下附加已运行的游戏通常需要 sudo；没有密码时会给出提示并尝试无密码运行。

> 三种方式不要同时开。日常推荐 A；A 万一被 Steam 拦，直接用 B。

## 四、自动识别说明

附加成功后界面顶部出现 **🧠 自动识别** 卡片：

- 游戏名（已收录的会标注"已收录"，未收录显示 exe 名并套用通用配方）
- 引擎：Unity / Unreal Engine / REDengine / Godot / Source / 未知
- 位数、内存占用、Steam AppID
- 属性预设按钮：点一下自动选好数值类型，并提示该搜什么（如"残尘 int32"、"生命 float"）

同时"⑤ 收藏自动恢复"会按模块+偏移复原你上次收藏的数值，标注 已恢复 / 值已变 / 失效。

## 五、搜索流程（通用套路）

### 改钱 / 弹药 / 点数（有数字显示）

1. 点属性预设按钮（或手动选类型），输入游戏里看到的数字 → **全类型搜索**。
2. 回游戏让数值变化，输入新数字 → **精确值**。重复到剩 1~3 个候选。
3. 逐行改值确认，命中后点 **锁定**（每 50ms 回写）。

### 改血量（血条没有数字）

1. 类型选"单精度小数"，点 **模糊快照**。
2. 回游戏被打一下 → **减少**；再被打 → **减少**。
3. 剩几条时逐行锁定，血条不再掉就是对了。

### 收藏自动重定位

1. 定位成功后点结果行的 **★**，起名（残尘/生命/欧元…）。
2. 下次开游戏自动恢复；失效的（堆地址变动）点"重搜"。

## 七、关于 .exe / "直接导入"

- `DeckTrainer` 就是 Linux 原生可执行文件，用法和 .exe 一样：双击运行，或在 Steam「库 → 添加非 Steam 游戏 → 浏览」里直接选它，就能从游戏模式启动。
- 没有提供 Windows `.exe`：Windows 程序在 SteamOS 上要经 Proton 跑在独立容器里，读不到另一款游戏的内存（跨 prefix 无法附加），做出来也用不了。当前的原生文件才是 Deck 上真正能用的形态。

## 八、出问题了怎么办

1. Konsole 运行：

   ```bash
   bash ~/DeckTrainer/诊断.sh
   ```

   生成 `~/DeckTrainer/诊断报告.txt`（系统、可执行文件、ptrace、端口、进程、日志、Steam 启动选项），发出来即可定位。

2. 常见现象：

| 现象 | 处理 |
| --- | --- |
| 加了启动选项游戏进不去 | 确认已升级到 v2.2；路径别加多余引号；仍不行就删掉启动选项，改用方式 B |
| 手机打不开页面 | 确认同一 Wi-Fi、IP 正确；看 `last_url.txt`（端口可能已自动切换） |
| 界面显示"未附加（自动识别中）" | 游戏还没进主界面，或进程不满足条件；点①刷新手动选；看日志 |
| 附加提示无法读取内存 | 用方式 A；或方式 B 下运行一次 `开放权限.sh` |
| 桌面模式 sudo 密码错误 | SteamOS 默认无密码，先 `passwd` |
| 搜到 0 个结果 | 换全类型搜索；数值可能显示取整，用模糊模式；少数游戏数值加密 |
| 写入没反应 | 多个候选逐个试，同一数值可能有两份，都要锁 |
| 锁定后闪退 | 锁错地址，解除并重启游戏（不写存档） |

- 端口：启动前设 `DECKTRAINER_PORT=9000`。
- 日志：`~/DeckTrainer/运行日志.txt`、`后台日志.txt`。

## 九、安全须知

- 仅单机离线使用；联机改内存可能触发反作弊。
- 网页界面对局域网开放（方便手机遥控），不要在不可信网络长期开启。
- 重要存档先备份。
